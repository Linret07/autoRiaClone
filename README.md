# AutoRia Clone — Full-Stack Web & REST API

Платформа для купівлі та продажу автомобілів на базі **Spring Boot 3**, **Spring Security (JWT)**, **Spring Data JPA**, хмарної бази даних **PostgreSQL (Neon)** та вбудованого веб-інтерфейсу (`HTML / CSS / Vanilla JS`).

---

## Технологічний стек

* **Java 17** & **Spring Boot 3.4**
* **Spring Security + JWT (JWS)** — безсесійна автентифікація та розмежування доступу за ролями й пермішинами (`@PreAuthorize`)
* **Spring Data JPA / Hibernate** — робота з БД, автоматична генерація та оновлення схеми
* **PostgreSQL 18 (Neon Cloud)** — основна реляційна база даних
* **PrivatBank Public API** — автоматичне отримання та кешування актуальних курсів валют (`USD`, `EUR`, `UAH`) із регулярним оновленням за розкладом (`@Scheduled`)
* **Frontend (Static Resources)** — адаптивний веб-інтерфейс у `backend/src/main/resources/static/` (`index.html`, `style.css`, `app.js`)
* **Lombok** — скорочення шаблонного коду

## Демо-доступ (тестові акаунти)

Під час першого запуску система (`DataInitializer`) автоматично створює тестових користувачів із різними ролями й тарифами, базові марки (`BMW`, `Daewoo`, `Toyota`), моделі (`X5`, `3 Series`, `Lanos`, `Camry`) та 3 стартові оголошення. Використовуйте ці облікові записи для входу через веб-інтерфейс (`http://localhost:8080/`) або в Postman:

| Роль / Тариф | Email (Логін) | Пароль | Що можна протестувати |
| :--- | :--- | :--- | :--- |
| **Seller (Premium)** | `premium@autoria.ua` | `premium123` | Безлімітне створення оголошень, перегляд аналітики переглядів і середніх цін |
| **Seller (Basic)** | `seller@autoria.ua` | `seller123` | Обмеження на 1 активне оголошення (спроба додати 2-ге поверне `403`), запит на нову марку |
| **Manager** | `manager@autoria.ua` | `manager123` | Модерація оголошень зі статусом `INACTIVE`, схвалення нових марок, бан користувачів |
| **Admin** | `admin@autoria.ua` | `admin123` | Повний адміністративний доступ до всіх ендпоінтів платформи |
| **Buyer** | `buyer@autoria.ua` | `buyer123` | Перегляд активних оголошень та актуальних курсів валют |

## Ключова бізнес-логіка

1. **Мультивалютність (USD / EUR / UAH):**
    * Продавець вказує ціну в будь-якій із 3 валют (`USD`, `EUR`, `UAH`).
    * Система автоматично перераховує суму в усі три валюти за актуальним курсом ПриватБанку та зберігає курс на момент створення/оновлення.
2. **Ліміт оголошень для Basic-акаунта:**
    * Продавець із типом `BASIC` може мати лише **1 активне оголошення**. При спробі створити друге повертається `403 Forbidden` із пропозицією оновити тариф до `PREMIUM`.
3. **Автоматична перевірка на нецензурну лексику (Profanity Filter):**
    * При створенні або редагуванні опису оголошення текст перевіряється на заборонені слова.
    * Дозволено до **3 спроб виправлення** (`EDIT_REQUIRED`). Після 3-ї невдалої спроби оголошення автоматично переводиться у статус `INACTIVE` і передається на ручну перевірку менеджеру.
4. **Аналітика для Premium-продавців (`GET /api/ads/{id}/analytics`):**
    * Підрахунок загальної кількості переглядів та переглядів за останні 1, 7 і 30 днів.
    * Розрахунок середньої ціни аналогічної марки/моделі авто в регіоні продавця та по всій Україні.
    * Для акаунта `BASIC` повертається `403 Forbidden`.
